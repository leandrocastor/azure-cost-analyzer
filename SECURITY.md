# Security Policy

Obrigado por ajudar a melhorar a segurança deste projeto.

## Reporting a Vulnerability

Se você identificar uma vulnerabilidade de segurança, por favor não abra uma Issue pública.

Entre em contato através de:

contato@castortech.com.br

ou utilize o recurso de Private Vulnerability Reporting do GitHub.

## Supported Versions

A branch main representa a versão suportada atualmente.
